# RecipeManager

Простое консольное приложение на C++ для управления списком рецептов на день и учета калорий.

## Функционал
- Добавление новых рецептов.
- Удаление рецептов.
- Просмотр списка и подсчет калорий.
- Сортировка рецептов по калорийности.
- Автоматическое сохранение в файл `recipes.txt`.

## Как использовать
1. Скомпилируйте проект с помощью любого компилятора C++ (например, через Visual Studio).
2. Запустите полученный `.exe` файл.
3. Следуйте инструкциям в консольном меню.

## Технологии
- C++
- Работа с файловой системой (fstream)
